# CLAUDE.md — правила проекта maxdone

Этот файл читается Claude Code автоматически. Он задаёт, как ведётся разработка.

## Главный принцип: приоритет истины
1. **Спека определяет поведение** — папка `spec/` это источник истины.
2. **Тесты выводятся из спеки** — `tasks/tests/` это арбитр.
3. **Код подчиняется тестам** — реализация верна, если проходит тесты.

При конфликте: спека > тесты > код. Никогда не «чинить» тест, подгоняя его
под неверный код — сначала проверь, что говорит спека.

## Зоны генерации
**Регенерируется из спеки (детерминированно), см. `spec/01_domain.md`:**
- `tasks/models.py` — модели, поля, enum
- миграции
- сериализаторы (когда появятся)

**Выводится из спеки как тесты, см. `spec/02_rules.md`:**
- `tasks/tests/` — поведенческие тесты бизнес-правил

**Пишется руками под присмотром (спека описывает, но не генерирует 1:1):**
- вьюхи, HTMX-фрагменты, шаблоны (`spec/03_api_ui.md` задаёт контракт)
- синхронизация, безопасность, производительность — НЕ генерировать,
  это зона архитектурных решений человека

## Две дорожки изменений (детали в WORKFLOW.md)
- **Дорожка A (правлю спеку):** изменить `spec/` → регенерировать затронутые
  детерминированные артефакты → прогнать тесты → дифф → коммит.
- **Дорожка B (правлю код по-быстрому):** изменить код → тесты ДОЛЖНЫ остаться
  зелёными. Если изменилось ПОВЕДЕНИЕ — обязательно обнови `spec/` и тесты,
  иначе расхождение. Падающий тест = сигнал, что спека и код разошлись.

## Запрещено
- Менять enum-значения `Horizon`/`State`/`Type` без правки `spec/01_domain.md`
  (они происходят из оригинального APK, ломать совместимость нельзя).
- Генерировать код синхронизации автоматически.
- Править тест, чтобы он «прошёл», не сверившись со спекой.

## Стек и команды
- Django 5 + PostgreSQL, HTMX + Alpine + Tailwind, docker-compose.
- Тесты: `docker compose exec web python manage.py test`
- Миграции: `docker compose exec web python manage.py makemigrations && migrate`
- Сборка CSS: `docker compose --profile assets up tailwind`
- Конвенции: веса шрифта только 400/500; sentence case; токены из tailwind.config.js.
